# ชุดทดสอบ RPC / RLS ของ Chemistria

ทดสอบกับ Postgres ในเครื่อง (ไม่แตะ Supabase จริง): สร้างฐานข้อมูลชั่วคราว → โหลด `stub.sql`
(บทบาท anon/authenticated + ฟังก์ชัน auth จำลอง) → โหลด `db/setup_all.sql` → รัน `rpc_tests.sql`

```
cd tests && ./run.sh        # ต้องมี psql + สิทธิ์สร้างฐานข้อมูล · ผ่านทั้งหมดจะออกด้วยรหัส 0
SETUP=/path/to/other.sql ./run.sh   # ลองกับ SQL อื่น (เช่นจำลองบั๊กเพื่อดูว่าชุดทดสอบจับได้)
```

ครอบคลุม (36 ข้อ): ทุกตารางเปิด RLS · นโยบายผูก is_teacher() · anon เรียก admin_* ไม่ได้ · ไม่มีฟังก์ชันเปิดให้ PUBLIC ·
นักเรียน/anon มองไม่เห็นข้อมูลตาราง · ล็อกอินและล็อก PIN · รางวัลไม่ซ้ำ/EXP ไม่ติดลบ · เช็กชื่อให้รางวัล ·
โปรโมชัน (รับครั้งเดียว/หมดอายุ) · ควิซประจำวัน (ห้องเฉพาะ/ส่งซ้ำ) · กาชาเหรียญไม่พอ · โหมดส่อง (41 ฟังก์ชันถูกบล็อก) ·
health_check และ game_stats

**เมื่อเพิ่ม SQL ใหม่:** ต่อชื่อไฟล์ใน cat ของ `setup_all.sql` (ดู README หลัก) แล้วรัน `./run.sh` ก่อนปล่อยทุกครั้ง
**เมื่อเพิ่มฟังก์ชันใหม่สำหรับนักเรียน:** ถ้าอ่านอย่างเดียวและควรให้โหมดส่องใช้ ต้องเพิ่มใน allow-list ของ `_sid` และในข้อทดสอบ "โหมดส่อง"
