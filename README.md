## ติดตั้ง 5 ขั้นตอน

1. **สร้างโปรเจกต์ Supabase** (supabase.com → New project, ภูมิภาค Singapore ใกล้ไทยที่สุด)
2. **ฐานข้อมูล**: เมนู SQL Editor → วางเนื้อหา `db/setup_all.sql` (ไฟล์เดียวรวมทั้งหมด) แล้วกด Run (ถ้าอยากแยกขั้น ใช้ `01_schema.sql` แล้วตามด้วย `02_seed.sql`)
3. **บัญชีครู**: Authentication → Users → Add user ใช้อีเมล `noppawit@nonghanwit.ac.th` ตั้งรหัสผ่าน ติ๊ก Auto Confirm
   (อีเมลนี้ถูกใส่ในตาราง `teachers` ไว้แล้ว ถ้าจะใช้อีเมลอื่นให้แก้ใน `02_seed.sql` หรือเพิ่มแถวในตาราง `teachers`)
   แนะนำ: Authentication → Sign In / Providers → ปิด “Allow new users to sign up”
4. **ตั้งค่าเว็บ**: เปิด `web/config.js` ใส่ Project URL และ anon (publishable) key จาก Project Settings → API
5. **ขึ้นเว็บ**: อัปโหลดโฟลเดอร์ `web/` ขึ้น GitHub Pages (หรือ Netlify) แล้วเข้า `…/admin.html` ล็อกอินครู

## กติกาที่ตั้งไว้ (แก้ได้ในแอดมิน)

| เรื่อง | ค่าเริ่มต้น |
|---|---|
| มาตรงเวลา / มาสาย | +5 EXP +2 เหรียญ / +2 EXP +1 เหรียญ |
| ส่งงาน / ส่งช้า | ตามที่ตั้งในงานแต่ละชิ้น / ได้ครึ่งหนึ่ง |
| เควสประจำวัน | สุ่มให้วันละ 3 ข้อ (รายสัปดาห์แสดงทุกข้อ) ครูอนุมัติแล้วจึงได้รางวัล |
| กาชา | 30 เหรียญ/ครั้ง, ×10 ได้, การันตี SR ขึ้นไปทุก 10 ครั้ง |
| เลเวล | EXP ที่ใช้ถึงเลเวล L = 40 × (L−1)² ; ยศ Bronze→Silver→Gold→Platinum→Diamond→Legend |
| สิทธิพิเศษ | นักเรียน “ขอใช้” ครูเป็นผู้อนุมัติทุกครั้ง |
| สมุดคะแนน | รวมคะแนนดิบแบบบวกตรง ไม่ปรับสัดส่วน · คะแนนพิเศษรวมไม่เกินเพดานต่อห้อง (ค่าเริ่มต้น 5) |

**“เก็บเวลา”** ในระบบนี้ = มาตรงเวลา / มาติดต่อกัน (สตรีค) / ส่งงานตรงเวลา แล้วปลดล็อก Achievement พร้อมรางวัล

## แรงค์ คลาส และภาพ (รอบที่ 2)

- **แรงค์สไตล์ LoL** Iron → Bronze → Silver → Gold → Platinum → Emerald → Diamond (แต่ละแรงค์มีดิวิชัน IV→I และแถบ LP) → Master → Grandmaster → Challenger กรอบอวาตาร์เปลี่ยนสีตามแรงค์ ตั้งค่า EXP ของแต่ละแรงค์ได้ที่แอดมิน → ตั้งค่า
- **แถบเลเวล** แสดงขีดทุก 10% ของ EXP ที่ต้องใช้ในเลเวลนั้น
- **คลาส 4 แบบ** (เลือกครั้งแรกฟรี เปลี่ยนครั้งละ 100 เหรียญ ปรับราคาได้):
  นักเล่นแร่แปรธาตุ = เหรียญจากเช็คชื่อ/งาน/เควส +25% · นักทดลอง = EXP +15% · ผู้พิทักษ์ = โล่ทีม: เพื่อนทีมเดียวกันมาสาย/ส่งช้ายังได้รางวัลเต็ม · นักล่าโชค = กาชาการันตี SR+ ทุก 8 ครั้ง
- **ภาพจาก Canva**: `art_src/` เก็บชีตต้นฉบับ (อวาตาร์ ตราแรงค์ ไอเทม) สคริปต์ `tools/slice_art.py` ตัดเป็นไฟล์ใน `web/assets/` — ถ้าได้ไฟล์ชีตความละเอียดสูงกว่า วางทับชื่อเดิมใน `art_src/` แล้วรันสคริปต์ซ้ำ
- อัปเกรดจากรอบแรก: รัน `db/setup_all.sql` ซ้ำทั้งไฟล์ (ข้อมูลเดิมไม่หาย)

## ความปลอดภัย

- นักเรียนไม่เข้าตารางโดยตรง เรียกได้เฉพาะฟังก์ชันที่ตรวจ token จากการล็อกอินเลขที่ + PIN
- PIN ผิด 5 ครั้งล็อก 10 นาที · PIN เก็บแบบแฮช (bcrypt)
- ครูเข้าได้เฉพาะอีเมลที่อยู่ในตาราง `teachers` ผ่าน Row Level Security
- อันดับห้องแสดงชื่อ + อวาตาร์ของเพื่อน 10 อันดับแรก (ถ้าไม่ต้องการ แจ้งให้ปรับเป็นนามแฝงได้)

## รอบที่ 7 — ฟังก์ชันแนะนำ 8 ข้อ (`db/08_features.sql`)
1. **รางวัลทันที:** ครูเช็คชื่อว่ามา/สาย → ได้ EXP ทันที + **ตั๋วสุ่มกาชาฟรี 1 ใบ** + เควส “มาเรียนวันนี้” สำเร็จอัตโนมัติ (ตั้งเควสอื่นเป็นอัตโนมัติได้ที่แท็บเควส คอลัมน์ “อัตโนมัติ”) · ส่งงานออนไลน์/ส่งรูปได้ EXP ทันที
2. **เตือนงานค้าง:** หน้าแรกแสดงงานเลยกำหนดและใกล้ครบกำหนด (≤3 วัน) พร้อม EXP ที่จะได้ และปุ่มส่งเลย
3. **ทีม/ห้องแข่ง:** แท็บแอดมิน “ทีม” สุ่มแบ่งทีม/ย้ายสมาชิก · นักเรียนดูอันดับทีมและห้องที่แท็บ “อันดับ” (EXP เฉลี่ยต่อคนของสัปดาห์นี้)
4. **สรุปรายสัปดาห์:** แท็บแอดมิน “สรุปสัปดาห์” (ขาดเรียน/ค้างส่ง/ไม่เข้าเว็บ/Top EXP) คัดลอกเป็นข้อความส่ง LINE ได้
5. **ควิซตามบท:** แท็บ “มินิเกม” ตั้ง “บทที่กำลังเรียน” ของห้อง + วางคำถามหลายข้อพร้อมกัน
6. **ส่งออก Excel:** แท็บ “ส่งออก Excel” (5 ชีตต่อห้อง หรือคะแนนรวมทุกห้อง)
7. **ส่งงานเป็นรูป:** แท็บ “งาน/การส่ง” คอลัมน์ “วิธีส่ง” (ครูบันทึกเอง / ออนไลน์ / ส่งรูป) · รูปเก็บใน Supabase Storage bucket `submissions` (Private, ≤1.5MB, JPEG; ย่อรูปในเบราว์เซอร์ก่อนอัป) · ครูกด “ดูรูป” / “ส่งคืน” (หัก EXP คืน ให้ส่งใหม่ได้)
   - ถ้ารัน SQL แล้วเห็น NOTICE ว่าตั้งค่า Storage ไม่สำเร็จ: สร้าง bucket `submissions` (Private) เองใน Supabase → Storage แล้วรัน SQL ใหม่
8. **บอสประจำสัปดาห์:** แท็บ “บอส” (เลือดต่อคน × จำนวนนักเรียน · ความเสียหาย = EXP เควสที่สำเร็จของทั้งห้อง) · ปราบได้ → คนที่ช่วยโจมตีรับรางวัล

## รอบที่ 9 — สเตตัสนักเรียน (`db/09_stats.sql`)
